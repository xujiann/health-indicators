# 国家·辽宁·大连公开指标查询分析系统

公开统计数据与经确认可公开的副省级城市对标数据查询分析系统，适合快速完成国家、辽宁省、大连市及对标城市之间的指标检索、横向对比、历年趋势查看和材料文字摘录。

## 在线访问

GitHub Pages 发布后访问：

`https://xujiann.github.io/health-indicators/`

## 功能

- 关键词检索：支持按指标名、对标口径、地区、来源部门和备注搜索。
- 专题入口：支持一键切换全国卫健公报、国家医保专题、2025 官方快报、卫生资源对标、大连趋势、统计公报补录、全国长序列 7 个常用视角。
- 多级筛选：支持全国、省区市、副省级城市层级，以及发布部门、类别、子类、单年和时间跨度筛选；筛选结果可直接生成跨年度趋势。
- 对比分析：自动识别横向对比、历年趋势、目标约束类指标，并生成图表卡片。
- 明细列表：保留逐条数据表，便于核验来源、年度、单位和备注。
- 分析工作台：提供自动洞察、指标知识、趋势构建、城市画像、对比篮、数据质量、时间轴、更新中心和专题模板 9 个分析页签。
- 覆盖维护：提供 15 城市 × 6 年度 × 7 核心指标覆盖矩阵、缺口筛选、标准补录台账下载和来源索引替换清单。
- 材料复用：支持复制摘要、表格、来源、来源缺口及导出 CSV，卡片也可一键复制为材料文字。

## 数据内容

- `index.html`、`app-core.js`、`analysis-workbench.js`：可直接托管到 GitHub Pages 的静态查询分析系统；核心计算已经从页面拆出，便于单元测试和复用。
- `public-data.js`：由版本化原始数据确定性生成的数据脚本。使用脚本形式而不是网络请求，确保通过 `file://` 直接打开时仍可离线查询。
- `data/base-public-records.json` 与 `data/*-additions.json`：公开数据的唯一事实源；页面数据和 Excel 工作簿均为生成物，不再反向作为更新输入。
- `data/public-data-manifest.json`：生成数据的行数、字段和 SHA-256 校验信息。
- `coverage.html`、`data/coverage-report.json`、`docs/数据覆盖率报告.md`：15 个副省级城市 2020—2025 年核心经济、人口和财政指标覆盖矩阵及维护页。
- `data/subprov-core-matrix-backlog.csv`、`docs/城市核心指标补录工作流.md`：可填写的缺口台账和经过严格预检后写入事实源的补录流程。
- `data/source-index-backlog.csv`、`data/source-provenance-overrides.json`、`docs/来源索引原文替换工作流.md`：来源索引替换台账、独立证据覆盖层和安全替换流程。
- `公开指标数据库.xlsx`：结构化公开数据，共 2701 条、19 个字段，包含 2010-2024 年全国卫生健康统计公报核心序列、2022-2024 年公报扩展分类指标、2016-2025 年全国人口老龄化长序列、1998-2025 年国家医保局医保数智库跨领域长序列、2023-2025 年国家医保局年度统计公报与快报专题、2025 年国家统计局卫生资源年度公报快报及 15 个副省级城市对标数据。
- `data/national-aging-population-additions.json`：民政部、全国老龄办《2025年度国家老龄事业发展公报》图表中的 2016-2025 年全国老龄人口数量、占比和抚养比长序列，归入“人口—人口规模与结构”。
- `data/national-economy-pop-health-insurance-additions.json`：国家医保局医保数智库公开的 1998-2025 年全国经济、人口、卫生、医保相关长序列数据；空白单元未录入，2025 年按官方说明标记为初步数据。
- `data/national-health-bulletin-additions.json`：国家卫健委 2010-2024 年卫生健康统计公报核心指标补录数据。
- `data/national-health-bulletin-expanded-additions.json`：国家卫健委 2022-2024 年卫生健康统计公报 PDF 表格扩展指标，按资源、人员、费用、服务、运行、疾控、妇幼、中医药等分类。
- `data/national-official-2025-health-insurance-additions.json`：国家统计局《2025 年国民经济和社会发展统计公报》卫生资源、服务量指标，以及国家医保局《2025 年医疗保障事业发展统计快报》参保、基金、待遇、生育、长护和异地结算指标；保留独立对比口径，便于与后续国家卫健委 2025 年公报核验。
- `data/national-medical-insurance-annual-bulletins-additions.json`：国家医保局 2023-2025 年《全国医疗保障事业发展统计公报》最终口径，涵盖参保、基金、待遇、生育、救助、目录、异地就医、基金监管和长期护理保险。
- `data/national-medical-insurance-quick-reports-additions.json`：国家医保局 2023-2024 年《医疗保障事业发展统计快报》核心初步口径；2025 年快报核心指标保留在 `national-official-2025-health-insurance-additions.json`。
- `data/stat-bulletin-additions.json`：相关城市 2024 年官方统计公报补录数据。
- `data/subprov-stat-bulletin-additions.json`：副省级城市 2023 年官方统计公报核心指标补录数据。
- `docs/数据字段说明.md`：字段口径和维护说明。
- `docs/统计公报补录说明.md`：统计公报补录范围、来源索引与维护原则。
- `docs/官方数据源巡检.md`：官方数据源巡检范围、自动检测边界和人工复核入库流程。
- `docs/国家医保数据专题说明.md`：国家医保专题的范围、指标分类、年度公报与快报并列规则及来源索引。
- `docs/发布与隐私边界.md`：公开发布边界和安全检查项。

## 数据范围与来源

本仓库含各级政府官网正式发布的统计公报、财政公开数据，以及经确认可公开的副省级城市对标数据，覆盖经济、人口、财政、卫生健康等指标。

本版已补入国家卫生健康委 2010-2024 年《我国卫生健康事业发展统计公报》核心序列，并对 2022-2024 年官方 PDF 中可稳定结构化的表格指标做扩展入库，覆盖卫生资源、床位资源、卫生人员、卫生费用、医疗服务、医院运行、基层卫生服务、中医药服务、疾病控制与公共卫生、妇幼与公共卫生、医疗质量与服务、健康结果等分类。截至本次核验尚未发现国家卫健委发布 2025 年同名统计公报，因此 2025 年卫生资源与服务量单独保留国家统计局年度公报口径。

另补入国家统计局 2025 年年度公报中的卫生资源与服务量，以及国家医保局 2025 年统计快报中的参保、基金和待遇指标。两组记录均保持来源专属的对比键，不把年度快报与国家卫健委同名统计公报视为同一口径。每周自动巡检官方栏目是否更新；发现新材料后仍需完成字段、单位和可比性复核，才会进入公开数据库。

“国家医保专题”现汇集国家医保局医保数智库长序列，以及 2023-2025 年年度统计公报和同期统计快报。专题内年度公报为最终可比口径，快报保留为初步统计口径；同年数值差异会保留来源说明，不自动互相替换。

城市侧已补入南京、广州、深圳、武汉、济南、沈阳、大连等城市 2024 年官方统计公报核心指标，并补入南京、广州、深圳、武汉、济南、沈阳 2023 年官方统计公报核心经济、人口、财政指标；副省级城市横向对标数据已按可公开口径处理。引用和正式使用时，请以原始公报或正式来源为准。

## 开发与发布校验

```powershell
npm ci
npm run build:data
npm test
```

常用命令：

- `npm run build:data`：从基础数据和补录数据生成 `public-data.js`、清单和覆盖率报告。
- `npm run import:subprov -- <补录.csv>`：只读预检副省级城市核心指标补录；人工复核后追加 `--write` 写入事实源。
- `npm run import:provenance -- <原文替换.csv>`：只读预检来源索引替换；人工复核后追加 `--write` 写入来源证据覆盖层。
- `npm run verify:generated`：确认已提交生成物与事实源一致；CI 会阻止生成物漂移。
- `npm run build:workbook`：使用 Codex 工作区提供的 `@oai/artifact-tool` 重建公开工作簿。
- `node scripts/verify-public-workbook.mjs`：核对工作簿与生成数据行数，并渲染“说明”“覆盖概览”“公开指标数据”三个工作表。
- `npm run watch:sources`：将当前官方来源与已确认基线比较。
- `npm run watch:update-baseline`：人工复核后接受当前来源状态为新基线。

`npm test` 会执行生成物校验、数据门禁、发布配置校验、核心逻辑单元测试和 Chromium 端到端测试。浏览器测试覆盖搜索、列表、专题 URL 恢复、CSV 导出、分析工作台键盘关闭、移动端溢出和工作簿下载。GitHub Pages 部署必须通过完整门禁。

工作簿生成使用 Codex 工作区提供的电子表格运行时；普通干净克隆只需 `npm ci && npm run build:data && npm test` 即可完成数据、页面和发布门禁的可复现验证。
