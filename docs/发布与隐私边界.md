# 发布与隐私边界

本仓库定位为公开在线系统，可开启 GitHub Pages。发布前应确认：

- 只包含公开统计公报、财政公开数据、政府官网已发布内容，以及经确认可公开的副省级城市对标数据。
- 不包含未确认公开的不予公开文件、征求意见稿、规划草案、重点工作任务等内部政策文件。
- `index.html` 内嵌数据与 `公开指标数据库.xlsx` 保持同一公开口径。
- 每条记录均有可打开来源；“来源索引”只表示官方公开入口，不包装成单条原文。
- 私有全量数据只进入 `health-indicators-private` 等私有仓库，不开启 Pages。

建议发布前执行敏感词扫描：

```powershell
rg -n "不予公开|征求意见稿|十五五规划|疾控规划|卫健规划|重点工作任务|仅限内部使用|内部文件" .
```

如果扫描命中公开页面或公开 Excel 中的真实数据内容，应先移除或改投私有仓库后再发布。

## 发布门禁

GitHub Pages 的 `deploy` 作业依赖 `quality` 作业。发布前执行：

```powershell
npm ci
npm test
```

门禁同时检查数据唯一键、年份和数值、PDF 碎片、缺失来源、待复核与内部标记，并通过 Chromium 验证搜索、列表、分析工作台、来源筛选和工作簿下载。`analysis-workbench.js` 与页面、文档、数据及公开工作簿一并进入 Pages 制品。
